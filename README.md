# Faculdade-FrontWeb-Responsivo
Adaptando portabilidade de usuários a diferentes dispositivos.

Página web desenvolvida com HTML, CSS e JavaScript puro, sem frameworks. O objetivo foi criar um grid responsivo com 6 blocos sobre estados brasileiros, adaptando o layout para diferentes tamanhos de tela.
Estrutura de arquivos
O projeto é dividido em 3 arquivos: index.html para a estrutura, style.css para o visual e script.js para as interações.
Os 6 estados abordados
São Paulo é o maior centro econômico do país, responsável por cerca de 32% do PIB nacional. Rio de Janeiro é Patrimônio Natural da Humanidade pela UNESCO, famoso pelo Carnaval e pelo Cristo Redentor. Bahia é o coração afro-brasileiro, com 932 km de litoral e Salvador como primeira capital do Brasil colonial. Amazonas é o maior estado do país, com 1,57 milhão de km² e 98% de floresta nativa preservada. Rio Grande do Sul é a principal região vinícola do Brasil, com forte herança europeia e cultura gaúcha. Pernambuco tem Olinda como Patrimônio da Humanidade e é berço do frevo e do maracatu.
Breakpoints (Media Queries)
A página se adapta em 4 tamanhos: acima de 1280px exibe 6 colunas para desktop, em 768px muda para 3 colunas no tablet, em 480px passa para 2 colunas no celular médio, e abaixo de 480px exibe 1 coluna única para smartphones.
Recursos do JavaScript
Relógio em tempo real no rodapé, efeito glitch animado no título ao carregar a página, e cursor personalizado com destaque ao passar sobre os cards.
